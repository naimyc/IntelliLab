## 📊 Market Analysis

### 🔍 Existing Solutions

| Category | Example | Limitation |
|----------|--------|-----------|
| AI Tools | ChatGPT, Copilot | Provide full solutions → passive learning |
| IDEs     | VS Code, IntelliJ | No guidance or learning support |
| PDFs/LMS | Assignments       | Static, no interaction or feedback |

---

### ⚠️ Identified Gap

Current tools either:
- give **too much help** (complete solutions), or  
- provide **no guidance at all**  

👉 Missing: a system that combines  
- task understanding  
- guided step-by-step solving  
- real-time feedback  

---

### 🎯 Intelli Lab Positioning

Intelli Lab bridges this gap by combining:
- AI-based task analysis  
- Guided learning approach  
- Interactive coding environment  

👉 Focus: **active learning instead of solution copying**
